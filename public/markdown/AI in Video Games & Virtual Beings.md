# Entertainment, Games & Social Platforms

> This card broadens the original game-AI topic into a practical directory for play, social media, emulation, and game creation tools.

## Game Engines & Creation

| Tool | Description | Platforms | Notes |
| --- | --- | --- | --- |
| [GDevelop](https://github.com/4ian/GDevelop) | Accessible cross-platform game engine for 2D and 3D games. | Cross-platform | Good for fast prototyping and education. |
| [Godot](https://github.com/godotengine/godot) | Open source 2D and 3D game engine. | Cross-platform | One of the strongest open engines available. |
| [s&box](https://github.com/Facepunch/sbox-public) | Modern Source 2-based game creation environment. | Cross-platform | Worth watching for moddable multiplayer projects. |
| [CARLA](https://github.com/carla-simulator/carla) | Open simulation platform for autonomous driving research. | Windows, Linux | Useful where games and simulation overlap. |

## Launchers, Libraries & Emulation

| Tool | Description | Platforms | Notes |
| --- | --- | --- | --- |
| [Heroic Games Launcher](https://github.com/Heroic-Games-Launcher/HeroicGamesLauncher) | Unified launcher for GOG, Epic, and related libraries. | Cross-platform | Great Linux and macOS companion for non-Steam libraries. |
| [Hydra](https://github.com/hydralauncher/hydra) | Open gaming platform focused on being one launcher for everything. | Cross-platform | Useful for library consolidation. |
| [Moonlight](https://github.com/moonlight-stream/moonlight-qt) | High-performance game streaming client. | Cross-platform | Good for remote desktop gaming and home streaming. |
| [Playnite](https://github.com/JosefNemec/Playnite) | Game library manager with broad integration support. | Windows | Excellent if you want a unified games dashboard. |
| [Dolphin](https://github.com/dolphin-emu/dolphin) | GameCube and Wii emulator. | Cross-platform, Android | Mature and highly capable emulator. |
| [UTM](https://github.com/utmapp/UTM) | Virtual machines for macOS and iOS. | macOS | Useful for retro or isolated game environments. |

| Tool | Description | Platforms | Notes |
| --- | --- | --- | --- |
