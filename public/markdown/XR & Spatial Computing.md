# Desktop Systems, OS Tools & Window Management

> This section now covers the day-to-day desktop stack: operating systems, launchers, window managers, system utilities, and machine-level tooling.

## Operating Systems & Desktop Platforms

| Tool | Description | Platforms | Notes |
| --- | --- | --- | --- |
| [Omarchy](https://github.com/basecamp/omarchy) | Opinionated Linux distribution focused on a polished modern setup. | General OS | Worth tracking if you want a curated Linux environment. |
| [openmediavault](https://github.com/openmediavault/openmediavault) | NAS-oriented operating system and management layer. | General OS | Good for storage-heavy home setups. |
| [Puter](https://github.com/HeyPuter/puter) | Web-based personal cloud environment and internet OS concept. | General OS | Interesting if you want app-like workflows in the browser. |

| [YunoHost](https://github.com/YunoHost/yunohost) | Friendly server administration layer for self-hosting. | General OS | Good if you want easier service management. |
