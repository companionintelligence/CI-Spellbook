# Creative Media, Design & AI Art Tools

> This section combines AI image stacks with the broader creative toolchain: graphics, CAD, whiteboards, video editors, and media processing.

## AI Image & Diffusion Workflows

| Tool | Description | Platforms | Notes |
| --- | --- | --- | --- |
| [AUTOMATIC1111](https://github.com/AUTOMATIC1111/stable-diffusion-webui) | Stable Diffusion web interface with a huge ecosystem of extensions. | Self-hosted | Still the default reference UI for many workflows. |
| [ComfyUI](https://github.com/comfyanonymous/ComfyUI) | Node-based diffusion workflow builder. | Self-hosted | Best fit for modular and reusable generation pipelines. |
| [Fooocus](https://github.com/lllyasviel/Fooocus) | Simpler diffusion interface that emphasizes prompting and outputs. | Self-hosted | Good starting point for creators who want less setup overhead. |
| [InvokeAI](https://github.com/invoke-ai/InvokeAI) | Creative engine for image generation with a polished web UI. | Cross-platform, Self-hosted | Strong professional-oriented image workflow. |
| [SD.Next](https://github.com/vladmandic/sdnext) | All-in-one image and video generation UI. | Self-hosted | Good when you want breadth in a single install. |
| [SwarmUI](https://github.com/mcmonkeyprojects/SwarmUI) | Modular Stable Diffusion interface with performance focus. | Cross-platform | Useful when you want power-user controls. |
| [WebUI Forge](https://github.com/lllyasviel/stable-diffusion-webui-forge) | Performance-tuned Stable Diffusion UI branch. | Self-hosted | Good if you want Forge-specific optimizations. |
