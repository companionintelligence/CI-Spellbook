# Entertainment, Games & Social Platforms

> This card broadens the original game-AI topic into a practical directory for play, social media, emulation, and game creation tools.

## Game Engines & Creation

| Tool | Description | Platforms | Notes |
| --- | --- | --- | --- |
| [Bevy](https://github.com/bevyengine/bevy) | Data-driven game engine in Rust with an ECS architecture; v0.18 in 2026. | Cross-platform | Rapid progress; still pre-1.0 but viable for indie projects. |
| [CARLA](https://github.com/carla-simulator/carla) | Open simulation platform for autonomous driving research. | Windows, Linux | Useful where games and simulation overlap. |
| [GDevelop](https://github.com/4ian/GDevelop) | Accessible cross-platform game engine for 2D and 3D games. | Cross-platform | Good for fast prototyping and education. |
| [Godot](https://github.com/godotengine/godot) | Open source 2D and 3D game engine; stable at v4.6+ in 2026. | Cross-platform | Default recommendation for most open-source game projects. |
| [s&box](https://github.com/Facepunch/sbox-public) | Modern Source 2-based game creation environment. | Cross-platform | Worth watching for moddable multiplayer projects. |

## Launchers, Libraries & Emulation

| Tool | Description | Platforms | Notes |
| --- | --- | --- | --- |
| [Dolphin](https://github.com/dolphin-emu/dolphin) | GameCube and Wii emulator. | Cross-platform, Android | Mature and highly capable emulator. |
| [Heroic Games Launcher](https://github.com/Heroic-Games-Launcher/HeroicGamesLauncher) | Launcher for GOG, Epic, and Amazon libraries on Linux, macOS, and Windows. | Cross-platform | Great Linux and macOS companion for non-Steam libraries. |
