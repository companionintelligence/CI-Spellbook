# Knowledge, Notes & Productivity Systems

> A curated stack for organizing information, writing, reading, planning, and keeping a private knowledge base that can evolve into a real operating system for work.

## Notes & Knowledge Bases

| Tool | Description | Platforms | Notes |
| --- | --- | --- | --- |
| [Affine](https://github.com/toeverything/AFFiNE) | Workspace combining docs, whiteboards (Edgeless mode), and databases; local-first. | Cross-platform | Strong Notion+Miro hybrid; best if you need real-time collab + canvas. |
| [Anytype](https://github.com/anyproto/anytype-ts) | Privacy-oriented object-based knowledge workspace with P2P local-first sync. | Cross-platform | Good for offline-first and complex linked data structures. |
| [AppFlowy](https://github.com/AppFlowy-IO/AppFlowy) | Open workspace combining docs, projects, and AI features; Rust+Flutter stack. | Cross-platform | Good if you want a Notion-like stack to self-host or extend. |
| [FastGPT](https://github.com/labring/FastGPT) | Knowledge platform built around RAG and workflow orchestration. | Cross-platform | Good bridge between notes and AI workflows. |
| [Foam](https://github.com/foambubble/foam) | VS Code-based personal knowledge system using markdown and graph views. | VS Code | Great for markdown-native graph notes inside your editor. |
| [Logseq](https://github.com/logseq/logseq) | Open-source block-based outliner and PKM platform; 43k+ stars, active June 2026. | Cross-platform | Strong daily-note and linked-thinking workflow; still actively maintained. |
| [Outline](https://github.com/outline/outline) | Fast collaborative knowledge base for teams. | Cross-platform | Good fit for internal docs and wikis. |
| [Siyuan](https://github.com/siyuan-note/siyuan) | Privacy-first self-hosted knowledge system with block-reference and spaced repetition. | Cross-platform | Feature-rich with built-in SRS; good for large personal platforms. |
| [Trilium Notes](https://github.com/TriliumNext/Trilium) | Deeply structured personal knowledge base. | Cross-platform | Useful for complex hierarchies and large note collections. |
