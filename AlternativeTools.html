win-acme: ACME Client for Windows

win-acme is an open-source, simple ACME client for Windows, primarily used with Let's Encrypt to automate the process of obtaining and renewing SSL/TLS certificates. Formerly known as letsencrypt-win-simple (LEWS), it facilitates the automatic generation and installation of certificates for IIS and other Windows-based servers.

🔑Key Features
  • Automated Certificate Management – Streamlines the issuance and renewal of SSL/TLS certificates, reducing manual intervention.
  • Broad Server Compatibility – Supports IIS and other Windows-based servers, making it versatile for various environments.
  • Plugin Support – Extensible through plugins, allowing integration with different DNS providers and validation methods.
  • Regular Updates – Actively maintained with frequent updates to enhance functionality and address issues.
🚀Recent Enhancements

The latest release (v2.2.9.1) includes:

  • New DNS validation plugins for DNSExit and Hetzner.
  • Expanded the total number of DNS validation plugins to 20.
  • Improved certificate handling by leveraging the BouncyCastle library for enhanced robustness.
